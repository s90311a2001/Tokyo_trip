# 東京・鎌倉・江之島 情侶旅遊攻略大全 — 設計大綱

## Context
兩人首次去東京，加上鎌倉、江之島。目標是一份「研究國內外社群（IG / Threads / Dcard / PTT / FB 社團 / 部落格 / 日本 & 英文網站）大家都去哪裡」後整理而成、**按主題分類、內容盡量豐富**的攻略大全。本檔為攻略設計大綱，各章內容依此撰寫於 `guide/` 下。

### 已知行程條件（來自機票截圖）
| | 航班 | 時間 | 機場 |
|---|---|---|---|
| 去程 | 星宇 JX804 | 12/25（五）15:00 → 19:00 | 桃園 T1 → **成田 T2** |
| 回程 | 星宇 JX805 | 1/2（六）20:10 → 23:20 | **成田 T2** → 桃園 T1 |

- 9 天 8 夜，實際完整遊玩日 = 12/26～1/1 共 7 天 + 1/2 半天
- **跨年檔期**是這趟最大特色也是最大風險：聖誕夜抵達、年末購物、跨年、初詣、初日出、福袋，但 12/29～1/3 很多店家/美術館/市場休息，鎌倉 1/1～1/3 人潮爆量 → 攻略要特別針對這點設計

## 攻略大綱（預計 12 個主題章節）

### 0. 封面 & 一頁速覽
- 行程總覽卡：航班、日期、住宿區、每日一句話主題
- 「這趟必做 TOP 15」：從社群熱度整理出的情侶必去清單
- 年末年始**營業日曆**：哪些地方 12/29～1/3 休、哪些反而只有這幾天有

### 1. 行前準備 ✈️
- 證件 / Visit Japan Web / 入境流程（成田 T2）
- 網路：eSIM vs 漫遊 vs Wi-Fi 機（社群推薦比較）
- 支付：Suica / PASMO（含 iPhone 錢包）、信用卡回饋、現金需求
- 天氣與穿搭：東京 12 月底～1 月初氣溫、情侶穿搭/拍照配色建議
- 必裝 App：Google Maps、乘換案內、Tabelog、GO 計程車、Klook/KKday
- 行李清單、退稅規則、禁帶物品

### 2. 交通全攻略 🚃
- 成田 → 市區：Skyliner / N'EX / 京成 Access 特急 / 利木津巴士 / 平價巴士 比較（含 12/25 晚上抵達的最佳選擇）
- 回程 1/2 從市區到成田的時間規劃（20:10 起飛 → 最晚幾點出發）
- 東京地鐵：Tokyo Subway Ticket 24/48/72h 划不划算、JR 山手線基本概念
- 鎌倉・江之島：小田急「江之島・鎌倉周遊券」、江之電一日券「のりおりくん」、JR 路線比較、建議動線（順時針/逆時針）
- 跨年夜特別班次、初日出臨時列車資訊
- 地圖：主要轉乘站（新宿、澀谷、東京站）避坑

### 3. 住宿區域選擇 🏨
- **重點評估上野、大塚**（使用者指定），並與新宿 / 澀谷 / 銀座・東京站 / 淺草 / 池袋 一起做比較表：到成田時間（上野有京成 Skyliner 直達）、到鎌倉/江之島時間、跨年夜回飯店便利性、周邊美食、價位、治安/安靜度
- 大塚：都電荒川線、離池袋一站、在地居酒屋與老店、OMO5 東京大塚等社群熱門飯店
- 各區推薦飯店（平價 / 中價 / 情侶夜景或設計旅店）
- **鎌倉/江之島住一晚**：海景旅館、可看初日出或七里濱夕陽的住宿、古民家/設計民宿；建議排哪一晚（與 1/1 初日出、避開初詣人潮一起評估）
- 換宿行李處理：宅急便 / 寄物櫃 / 只帶過夜包
- 跨年期間訂房注意事項、價格趨勢

### 4. 東京區域景點攻略 🗼（按區分）
每區包含：必去景點、社群熱門拍照點、周邊美食、建議停留時間、情侶亮點
- 淺草・晴空塔・上野（淺草寺、和服體驗、阿美橫町、上野公園）
- 澀谷・原宿・表參道（Shibuya Sky、澀谷十字路口、Miyashita Park、竹下通、明治神宮）
- 新宿（都廳免費展望台、思い出横丁、黃金街、歌舞伎町）
- 銀座・丸之內・東京站（東京站紅磚、丸之內聖誕燈飾、KITTE 屋頂）
- 六本木・麻布台・虎之門（麻布台之丘、teamLab Borderless、東京鐵塔、TOKYO NODE）
- 台場・豐洲（teamLab Planets、豐洲千客萬來、彩虹大橋夜景）
- 下北澤・吉祥寺・中目黑・谷根千（文青/古著/散步路線）
- 近年新景點 & 2026 年最新開幕（研究時補齊）

### 5. 鎌倉・江之島專章 🌊（建議排 1～2 天）
- 一日 / 兩日經典路線（含地圖動線）
- 鎌倉：鶴岡八幡宮、小町通、鎌倉大佛（高德院）、長谷寺、報國寺竹林、明月院、錢洗弁財天
- 江之電沿線：極樂寺、**鎌倉高校前（灌籃高手平交道）**、七里濱夕陽 & 富士山、腰越
- 江之島：江島神社、龍戀之鐘 & 戀人之丘（情侶必去）、Sea Candle 展望燈塔、岩屋洞窟、**「湘南の宝石」冬季燈飾**
- 美食：吻仔魚丼、Bills 七里濱、鴿子餅乾、江之島仙貝、海景咖啡
- 避開人潮的關鍵：**避開 1/1～1/3 鶴岡八幡宮初詣**；或反向利用「江之島初日出」

### 6. 年末年始・季節限定特輯 🎍（本趟獨家重點）
- 12/25 聖誕夜：抵達後還來得及看的燈飾（多數燈飾 12/25 最後一天 vs 延續到 2 月）
